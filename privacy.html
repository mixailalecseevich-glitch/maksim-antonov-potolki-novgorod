Политика конфиденциальности

Дата редакции: 6 ноября 2026 года. Это описание относится к тестовой версии сайта о натяжных потолках Максима Антонова. Если на сайте появятся формы, аналитика, рекламные инструменты или другие способы обработки данных, документ и порядок получения согласия будут пересмотрены до их включения.

Кто отвечает за сайт

Сайт подготовлен для Максима Антонова, исполнителя услуг по натяжным потолкам в Великом Новгороде. Для связи по вопросам этого сайта используйте профиль Максима на Авито. Полные реквизиты и отдельный адрес для обращений по персональным данным должны быть добавлены перед запуском сайта как постоянного коммерческого канала.

Какие данные сайт получает

В этой тестовой версии нет формы заявки, личного кабинета, встроенного чата, аналитики и рекламных пикселей. Сайт не просит у посетителя имя, телефон или адрес. Если вы нажмёте кнопку связи, откроется Авито; сообщения там обрабатываются по правилам этой платформы и в рамках общения с исполнителем.

Сайт может размещаться на GitHub Pages. По описанию GitHub, при посещении страниц платформа регистрирует IP-адрес для обеспечения безопасности сервиса. Владелец этого сайта не управляет такими серверными журналами.

Файлы cookie и настройки браузера

В тестовой версии не подключены аналитические или рекламные cookie. Для запоминания закрытия информационного сообщения сайт сохраняет на вашем устройстве одну отметку в localStorage. Это хранилище браузера, а не cookie; отметка не отправляется владельцу сайта. Её можно удалить через настройки браузера.

Если позже будут подключены метрики или реклама, на сайте появятся точные сведения о применяемых технологиях и подходящий механизм выбора до их запуска.

Внешние ссылки и фотографии

Сайт содержит ссылки на Авито и, после их получения, может содержать ссылки на ВКонтакте и MAX. При переходе действуют правила соответствующих сервисов. Фотографии потолков предоставлены для публикации в портфолио этого проекта.

Изменение документа

Актуальная редакция публикуется на этой странице. Для постоянного сайта документ следует дополнить подтверждёнными реквизитами исполнителя, адресом для запросов и описанием фактических процессов обработки данных.
