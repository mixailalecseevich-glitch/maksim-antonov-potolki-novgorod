# Тестовый сайт Максима Антонова

Статический сайт: откройте `index.html` в браузере или разместите содержимое папки в корне GitHub Pages. Главный переход к заявке ведёт на профиль Авито. Кнопки ВКонтакте и MAX отключены до получения настоящих ссылок.

## Визуальное направление

Версия от 07.11.2026 основана на двух референсах пользователя: тёмный фон, контрастная крупная типографика, тёплые золотые линии и акценты, кадр монтажа, компактные карточки работ. Изображения монтажника (`hero-installation-wide.png`, `hero-installation-portrait.png`) созданы как концептуальные иллюстрации и подписаны на странице. Портфолио ниже собрано из фотографий, переданных пользователем для публикации. Иконки в `assets/*.svg` взяты из Tabler Icons; условия лицензии в `assets/tabler-icons-LICENSE.txt`.

Меню на телефоне открывается кнопкой, ссылки ведут к разделам, фотографии в портфолио увеличиваются по нажатию, кнопки связи открывают объявление Максима на Авито. Контакты VK/MAX остаются неактивными до получения ссылок.

## Перед постоянной публикацией

1. Утвердить три цены и состав каждого варианта с Максимом. Сейчас на странице есть только подписанные ориентиры из открытых объявлений и местного рынка; они не являются прайсом Максима.
2. Получить реквизиты и отдельный контакт для обращений по персональным данным. Обновить `privacy.html` под фактические процессы.
3. Сайт доступен по прямой ссылке и открыт для индексации. Перед постоянной рекламой подтвердить цены и реквизиты, проверить путь заявки и при смене домена обновить canonical и sitemap.
4. Добавить реальные ссылки VK и MAX, если эти каналы будут обрабатываться.
5. При добавлении форм, аналитики или рекламных пикселей пересмотреть политику и механизм согласий до включения.

Никакие данные клиентов на сайте не собираются. Код не загружает внешние шрифты, карты, счётчики или виджеты. Уведомление на странице честно описывает одну локальную настройку браузера.
